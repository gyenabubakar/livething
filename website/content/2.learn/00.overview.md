The [Start](/start/introduction) section got a tiny app running. **Learn** is the guided tour: it teaches WSKit as one system, from the ground up, in the order the ideas build on each other. Read it top to bottom and you'll know enough to build real things.

WSKit is two packages — `@wskit/server` and `@wskit/client` — but they aren't two libraries that happen to talk. They're two halves of **one contract**. So every page here shows you the server half and the client half side by side, because that's how you actually build with it.

This section is a **tutorial, not a reference**. Each page teaches the idea and the smallest working version of both halves, then points you to the [Server](/server/overview) and [Client](/client/overview) sections for the full detail — every option, every method, every edge case. Learn the shape here; reach for the specifics there.
