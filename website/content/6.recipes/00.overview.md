The rest of the docs teach the pieces: [Start](/start/overview) gets you running, [Learn](/learn/overview) walks each feature from both sides, and the [Server](/server/overview) and [Client](/client/overview) guides hold the per-package detail. **Recipes** put the pieces together — each one is a complete, real app, built end to end, so you can see how the features combine and lift the pattern straight into your own project.

It opens with **Framework Hooks** — one page per UI framework ([React](/recipes/framework-hooks/react), [Vue](/recipes/framework-hooks/vue), [Svelte](/recipes/framework-hooks/svelte), [Solid](/recipes/framework-hooks/solid), [React Native](/recipes/framework-hooks/react-native)) — the few lines that bind the socket's reactive stores to that framework. It's the setup the app recipes here assume, so it comes first; everything after it is a full worked app.

## Why recipes

Learn shows one feature at a time, on its own. A real app is never one feature. A chat is rooms _and_ presence _and_ history _and_ auth, all at once; an AI app is streaming _and_ steering _and_ surviving a dropped connection. The gap between "I understand channels" and "I've built a chat" is exactly what these pages fill.

So each recipe names the LiveThing ingredients it leans on, then builds the whole thing — server and client — as code you can read top to bottom. When you want to go deeper on any one piece, the recipe links back to the Learn, Server, and Client pages that own it.

::note
These pages assume you've met the building blocks already. If a capability or primitive is new to you, follow its link into [Learn](/learn/overview) for the concept, then come back. Recipes are about _assembly_, not first contact.
::

## How to read them

Every app recipe is self-contained and follows the same shape: the use case, the ingredients it uses, the server, the client, and the contract flowing between them. **Framework Hooks** is the exception — it's the framework-wiring setup, not a worked app. If you haven't bound the socket to your UI framework yet, start with your framework's page ([React](/recipes/framework-hooks/react), [Vue](/recipes/framework-hooks/vue), [Svelte](/recipes/framework-hooks/svelte), [Solid](/recipes/framework-hooks/solid), [React Native](/recipes/framework-hooks/react-native)); otherwise start with [Chat App](/recipes/chat-app) — it touches the most features in one place — or jump straight to whichever is closest to what you're building.
