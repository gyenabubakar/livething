React Native runs the same WSKit client as the web — it has a global `WebSocket`, so `connect()` works out of the box, and the [React adapter](/recipes/framework-hooks/react) (`useStore`, `useIncoming`, requests) is exactly the same. There's no SSR to worry about either. What's different on mobile is the **environment**: an app gets backgrounded and the network flips constantly, so you'll want a [platform environment](/client/platform/overview) wired to React Native's signals.

## The React Native environment

A mobile environment maps `AppState` to visibility and NetInfo to network. Build it with `environment(...)`:

```ts [rn-environment.ts]
import { environment } from '@wskit/client/environment'
import { AppState } from 'react-native'
import NetInfo from '@react-native-community/netinfo'

export const ReactNativeEnvironment = environment({
  onVisibilityChange(callback) {
    const sub = AppState.addEventListener('change', (s) => callback(s === 'active'))
    callback(AppState.currentState === 'active') // report the current state now
    return () => sub.remove()
  },
  onNetworkChange(callback) {
    return NetInfo.addEventListener((state) => callback(state.isConnected ?? false))
  },
})
```

Then pass it to [`platform()`](/client/platform/overview), alongside `reconnection()` and `keepalive()`:

```ts [socket.ts]
import { client, connect, reconnection, keepalive, platform } from '@wskit/client'
import { ReactNativeEnvironment } from './rn-environment'
import type { ChatSocket } from '../server/chat'

export const socket = client<ChatSocket>()(
  connect('wss://example.com/ws'),
  reconnection(),
  keepalive(),
  platform({
    environment: ReactNativeEnvironment,
    backgroundDisconnectMs: 30_000, // drop the socket 30s after the app backgrounds
  }),
)
```

That gets you two mobile-critical behaviors for free:

- **Background disconnect** — when the app is backgrounded for a while, the socket closes (saving battery and a server connection) and reopens when the user returns. See [Background Disconnect](/client/platform/background-disconnect).
- **Network-aware reconnection** — on a flaky mobile network, retries pause while offline and fire the instant connectivity returns, instead of burning attempts. See [Network Aware](/client/platform/network-aware).

## Using the adapter

The React page's `useStore` works unchanged — create the socket once (above) and read any store through it:

```tsx [StatusDot.tsx]
import { useStore } from './use-store'
import { socket } from './socket'

function StatusDot() {
  const state = useStore(socket.state, 'closed')
  return <View style={state === 'open' ? styles.green : styles.grey} />
}
```

Because `platform()` is installed above, `socket.online` is available too — the same `useStore` gives you an offline banner that follows NetInfo:

```tsx [OfflineBanner.tsx]
import { useStore } from './use-store'
import { socket } from './socket'

function OfflineBanner() {
  const online = useStore(socket.online, true)
  return online ? null : <Banner>You're offline</Banner>
}
```

Every other store binds through the exact same `useStore` — quality and latency from `keepalive()`, the reconnection loop, and a channel's roster and status:

```tsx [Indicators.tsx]
import { useStore } from './use-store'
import { socket } from './socket'

const idle = { retrying: false, attempt: 0, nextRetryAt: null }

function SignalBars() {
  const quality = useStore(socket.quality, 'disconnected')
  const latency = useStore(socket.latency, null)
  return <Bars tier={quality} title={latency === null ? 'measuring…' : `${latency}ms`} />
}

function ReconnectBanner() {
  const { retrying, attempt } = useStore(socket.reconnection, idle)
  return retrying ? <Banner>Reconnecting… (attempt {attempt})</Banner> : null
}

function Roster() {
  const room = socket.channel('rooms', 'room-42')
  const members = useStore(room.members, new Map())
  const status = useStore(room.status, 'unsubscribed')
  if (status === 'subscribing') return <ActivityIndicator />
  return (
    <FlatList
      data={[...members.values()]}
      renderItem={({ item }) => <Text>{item.meta.username}</Text>}
    />
  )
}
```

## Receipts

Receipts are the same store shape — `chat.receivers` and `chat.readers` are each a `Map<identity, cursor>` (needs `inbox()` and `readReceipts()`, and `receivers` needs `broadcastReceipts: true` on the server channel), so a per-message tick is one more `useStore`:

```tsx [Ticks.tsx]
import { useStore } from './use-store'
import { socket } from './socket'

function Ticks({ seq }: { seq: number }) {
  const chat = socket.channel('chat')
  const receivers = useStore(chat.receivers)
  const readers = useStore(chat.readers)
  const read = [...readers.values()].some((m) => m >= seq)
  const received = [...receivers.values()].some((m) => m >= seq)
  return <Text>{read ? '✓✓ read' : received ? '✓✓' : '✓'}</Text>
}
```

## Surviving a cold start

If you use [durable streams](/client/streams/durable-and-resume), persist the `streamId` with `AsyncStorage` while the stream runs, and `resumeStream(...)` with it after the app is killed and relaunched — the mobile equivalent of resuming after a page reload. The connection itself reconnects on its own through `reconnection()`; this is only for picking a long stream back up across a full restart.

```tsx [useAiStream.ts]
import AsyncStorage from '@react-native-async-storage/async-storage'
import { socket } from './socket'

const KEY = 'ai-stream-id'

// While the stream runs, save its id so a relaunch can find it.
export async function startAiStream(prompt: string) {
  const handle = await socket.stream('ask-ai', { prompt })
  await AsyncStorage.setItem(KEY, handle.streamId)
  for await (const chunk of handle) appendToken(chunk.text)
  await AsyncStorage.removeItem(KEY) // finished cleanly — nothing to resume
}

// On cold start, re-attach if we saved an id last time.
export async function resumeAiStreamIfAny() {
  const streamId = await AsyncStorage.getItem(KEY)
  if (!streamId) return
  const resumed = socket.resumeStream('ask-ai', streamId)
  for await (const chunk of resumed) appendToken(chunk.text)
}
```
