In Vue the pattern is a composable that holds a `ref`, updates it when a [store](/client/overview#reactive-stores) changes, and cleans up with `onScopeDispose`. Write it once, generic over any store, and reuse it for every value.

In every example on this page, `./socket` is Huddle's client socket, as defined on the [Huddle page](/reference/huddle#the-client-socket). It installs `keepalive()`, `reconnection()`, `platform()`, `channels()`, `inbox()` and `readReceipts()`, which the stores below need.

## The adapter

`useStore` seeds a `ref` from `store.get()`, updates it on every change, and releases the subscription on dispose. Subscribing inside `onMounted` keeps it client-only, which is what you want under SSR (Nuxt):

```ts [useStore.ts]
import { onMounted, onScopeDispose, readonly, shallowRef } from 'vue'
import type { ReadableStore } from '@livething/client'

export function useStore<T>(store: ReadableStore<T>) {
  const value = shallowRef(store.get())
  let off: (() => void) | undefined

  onMounted(() => {
    value.value = store.get() // catch any change between setup and mount
    off = store.subscribe((v) => {
      value.value = v
    })
  })
  onScopeDispose(() => off?.())

  return readonly(value)
}
```

```vue [StatusDot.vue]
<script setup lang="ts">
import { socket } from './socket'
import { useStore } from './useStore'

const state = useStore(socket.state)
</script>

<template>
  <span :class="state === 'open' ? 'green' : 'grey'">{{
    state
  }}</span>
</template>
```

`onScopeDispose` runs when the component (or effect scope) is torn down, so the subscription is always released. Because `useStore` takes any `ReadableStore`, the next sections are just different arguments.

## Connection quality

With [`keepalive()`](/client/primitives/keepalive), `socket.quality` and `socket.latency` are stores — the same `useStore`, nothing new:

```vue [SignalBars.vue]
<script setup lang="ts">
import { socket } from './socket'
import { useStore } from './useStore'

const quality = useStore(socket.quality)
const latency = useStore(socket.latency)
</script>

<template>
  <Bars
    :tier="quality"
    :title="latency === null ? 'measuring…' : `${latency}ms`"
  />
</template>
```

## Reconnection status

With [`reconnection()`](/client/primitives/reconnection), `socket.reconnection` is a store of `{ retrying, attempt, nextRetryAt }` — the same `useStore` drives a reconnecting banner:

```vue [ReconnectBanner.vue]
<script setup lang="ts">
import { socket } from './socket'
import { useStore } from './useStore'

const reconnection = useStore(socket.reconnection)
</script>

<template>
  <Banner v-if="reconnection.retrying"
    >Reconnecting… (attempt {{ reconnection.attempt }})</Banner
  >
</template>
```

## Network status

With [`platform()`](/client/platform/overview), `socket.online` follows the environment's network signal — one more store through the same composable:

```vue [OfflineBanner.vue]
<script setup lang="ts">
import { socket } from './socket'
import { useStore } from './useStore'

const online = useStore(socket.online)
</script>

<template>
  <Banner v-if="!online">You're offline</Banner>

```

## Channel presence

`channel.members` and `channel.status` flow through `useStore` too:

```vue [Roster.vue]
<script setup lang="ts">
import { socket } from './socket'
import { useStore } from './useStore'

const room = socket.channel('rooms', 'room:general')
const members = useStore(room.members)
const status = useStore(room.status)
</script>

<template>
  <Spinner v-if="status === 'subscribing'" />
  <ul v-else>
    <li v-for="[id, m] in members" :key="id">
      {{ m.meta.name }}
    </li>
  </ul>
</template>
```

## Receipts

`dm.receivers` and `dm.readers` are channel stores too — each a `Map<userId, cursor>` of how far the other person has received (grey check) or read (blue check). `receivers` fills only because the `dms` family calls `inbox()` (for receivers) and `readReceipts()` (for readers). The same `useStore` drives a per-message tick:

```vue [Ticks.vue]
<script setup lang="ts">
import { computed } from 'vue'
import { socket } from './socket'
import { useStore } from './useStore'

const props = defineProps<{ pair: string; seq: number }>()
const dm = socket.channel('dms', `dm:${props.pair}`)
const receivers = useStore(dm.receivers) // Map<userId, receivedThrough>
const readers = useStore(dm.readers) // Map<userId, readThrough>

const state = computed(() =>
  [...readers.value.values()].some((m) => m >= props.seq)
    ? 'read'
    : [...receivers.value.values()].some((m) => m >= props.seq)
      ? 'received'
      : 'sent',
)
</script>

<template>
  <Check :state="state" />
</template>
```

## Incoming events

`socket.on(event, handler)` returns an unsubscribe — store it and release it on dispose. Type the composable over the contract's incoming events so the event name is checked and the payload is inferred, no cast:

```ts [client/useIncoming.ts]
import { onMounted, onScopeDispose, shallowRef } from 'vue'
import { socket } from './socket'
import type { HuddleSocket } from '../server/huddle-definition'

type Incoming = HuddleSocket['incoming']

export function useIncoming<E extends keyof Incoming & string>(
  event: E,
) {
  const data = shallowRef(undefined as Incoming[E] | undefined)
  let off: (() => void) | undefined

  onMounted(() => {
    off = socket.on(event, (d) => {
      data.value = d
    })
  })
  onScopeDispose(() => off?.())

  return data
}
```

```vue [Notifications.vue]
<script setup lang="ts">
import { useIncoming } from './useIncoming'

const note = useIncoming('notification') // ShallowRef<{ title: string; body: string } | undefined> — inferred
</script>

<template>
  <Toast v-if="note">{{ note.title }}</Toast>
</template>
```

## Requests

A request is an async call; expose its result and error as refs:

```ts [useProfile.ts]
import { shallowRef, watchEffect } from 'vue'
import { socket } from './socket'

const getProfile = (userId: string) =>
  socket.request('get-profile', { userId })
type Profile = Awaited<ReturnType<typeof getProfile>>

export function useProfile(userId: () => string) {
  const profile = shallowRef(undefined as Profile | undefined)
  const error = shallowRef(undefined as unknown)

  watchEffect((onCleanup) => {
    let active = true
    onCleanup(() => {
      active = false
    })
    getProfile(userId())
      .then((p) => active && (profile.value = p))
      .catch((e) => active && (error.value = e))
  })

  return { profile, error }
}
```

`watchEffect` re-runs when `userId()` changes, and the `active` flag drops a stale response — the Vue equivalent of React's cleanup guard.

## Connecting and SSR

Open the socket once near the root — in your root component's `onMounted`, or a small client plugin — so it never runs during SSR:

```ts [app.client.ts]
import { socket } from './socket'

socket.connect()
```

This socket is created once at module scope and is meant to live for the app's whole lifetime, so — unlike a per-component connection — the root `connect()` needs no matching `disconnect()` on unmount. Call `socket.disconnect()` only when you genuinely want to tear the shared connection down (say, on logout); `reconnection()` handles ordinary drops on its own.

Because `useStore` subscribes in `onMounted` and starts from `socket.state.get()` (which is `'closed'` before connecting), the markup renders the same on the server and the first client paint, avoiding a hydration mismatch. See [SSR Safety](/client/connecting/ssr-safety) for the full picture.
