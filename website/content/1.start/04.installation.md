WSKit is split across a few packages. You install the client where your UI lives, and the server plus one platform adapter where your backend lives. Both share `@wskit/core`, which the commands below include for you.

## The packages

| Package                    | Where it runs                                   | What it is                                                                                       |
| -------------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `@wskit/client`            | Browser, React Native, Node, Bun, Deno, Workers | The typed client socket                                                                          |
| `@wskit/server`            | Your backend                                    | The server framework (`server`, capabilities, `InferClient`)                                     |
| `@wskit/server-cloudflare` | Cloudflare Durable Objects                      | Platform adapter                                                                                 |
| `@wskit/server-bun`        | Bun                                             | Platform adapter                                                                                 |
| `@wskit/server-node`       | Node.js                                         | Platform adapter                                                                                 |
| `@wskit/server-deno`       | Deno                                            | Platform adapter                                                                                 |
| `@wskit/core`              | Shared                                          | Wire protocol, errors, `CloseCodes` — the shared peer dependency, included in the commands below |

::note
`@wskit/core` is a peer dependency of both `@wskit/client` and `@wskit/server`. The commands below install it explicitly, so it works the same on npm, pnpm, yarn, and bun.
::

## Client

Install in the project that holds your UI:

::code-group

```bash [npm]
npm install @wskit/client @wskit/core
```

```bash [pnpm]
pnpm add @wskit/client @wskit/core
```

```bash [bun]
bun add @wskit/client @wskit/core
```

```bash [yarn]
yarn add @wskit/client @wskit/core
```

::

## Server

Install `@wskit/server` plus the adapter for your platform. Pick one adapter.

### Cloudflare Durable Objects

::code-group

```bash [npm]
npm install @wskit/server @wskit/server-cloudflare @wskit/core
```

```bash [pnpm]
pnpm add @wskit/server @wskit/server-cloudflare @wskit/core
```

```bash [bun]
bun add @wskit/server @wskit/server-cloudflare @wskit/core
```

```bash [yarn]
yarn add @wskit/server @wskit/server-cloudflare @wskit/core
```

::

The Cloudflare adapter requires a `compatibility_date` of `2026-04-07` or later in your `wrangler.jsonc`:

```jsonc [wrangler.jsonc]
{
  "compatibility_date": "2026-04-07",
}
```

### Bun, Node.js, and Deno

Install `@wskit/server` plus your runtime's adapter — `@wskit/server-bun`, `@wskit/server-node`, or `@wskit/server-deno`. The server code you write is identical to the Cloudflare block above; only the adapter package changes.

```bash [npm]
npm install @wskit/server @wskit/server-node @wskit/core
```

Swap `@wskit/server-node` for `@wskit/server-bun` or `@wskit/server-deno`, and use your runtime's own installer (`bun add`, `deno add`) if you prefer.

## Schemas

WSKit validates payloads with any [Standard Schema](https://standardschema.dev) validator — valibot, Zod, ArkType, and others. The examples in these docs use [valibot](https://valibot.dev), which `@wskit/server` already depends on:

::code-group

```bash [npm]
npm install valibot
```

```bash [pnpm]
pnpm add valibot
```

```bash [bun]
bun add valibot
```

```bash [yarn]
yarn add valibot
```
