WSKit is a typed WebSocket framework in two packages — `@wskit/server` and `@wskit/client` — that share one inferred contract. You declare your events once on the server, and the client picks up the exact same types with nothing to keep in sync by hand.

## The 30-second pitch

Write a server with `define`, register handlers, and call `base.assemble(...)`. Export one type with `InferClient`. Import that type on the client. Now `socket.on()`, `socket.send()`, requests, and channels are all typed end to end — a wrong event name or payload shape is a compile error, not a runtime surprise.

Both sides are opt-in. The server adds features as **capabilities** you list; the client adds them as **primitives** you pass. You only pay (in bundle size) for what you import — a minimal client is about **4.4 KB gzipped**.
