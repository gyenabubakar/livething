LiveThing keeps the main package imports small and exposes server and client capabilities through stable subpaths. The package names below are the public exports from each package's `package.json`.

## `@livething/core`

| Import            | Use                                                                                                                                                                                      |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@livething/core` | Shared `LiveThingError` definitions, built-in errors, `CloseCodes`, wire types, validators, identifier helpers, and the binary frame helpers `encodeBinaryFrame` and `splitBinaryFrame`. |

## `@livething/client`

| Import                          | Use                                                                                                                                                         |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@livething/client`             | `client`, `connect`, client primitives, socket and contract types, `PrimitiveFactory`, `ServerRequestsOf`, `Message`, `WireFrame`, and `LiveThingMetadata`. |
| `@livething/client/errors`      | Client errors (`Timeout`, `Disconnected`, `Dropped`, `StreamCorrupted`) and shared error helpers such as `LiveThingError` and `Block`.                      |
| `@livething/client/environment` | `environment`, `WebEnvironment`, and `ClientEnvironment`.                                                                                                   |
| `@livething/client/platform`    | Platform helpers and `PlatformOptions`.                                                                                                                     |
| `@livething/client/testing`     | `inject` and `injectChannel` for pushing test messages through the real client pipeline.                                                                    |

`PrimitiveFactory` is the type used when declaring a client primitive dependency. `ServerRequestsOf<T>` extracts the server-request map from a contract; both are type-only exports from the main client entry point.

## `@livething/server`

| Import                              | Use                                                                                                                                                                                                                                                   |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@livething/server`                 | `server`, `context`, `emits`, `errors`, `InferClient`, the `OutgoingFrame` and `OutgoingTarget` types of the `onOutgoing` hook, shared server context types (including `SQLProvider` and `SqlResult`), and core server helpers.                       |
| `@livething/server/adapters`        | Adapter types (including the `TransportFrame` a socket descriptor sends), the adapter factory, `asUint8Array` for binary messages, and `rejectAsyncTransactionCallback` and `rejectAsyncTransactionResult` for a custom SQL provider's `transaction`. |
| `@livething/server/errors`          | Server error definitions and server-side error helpers.                                                                                                                                                                                               |
| `@livething/server/client-requests` | The `clientRequests()` capability.                                                                                                                                                                                                                    |
| `@livething/server/server-requests` | The `serverRequests()` capability.                                                                                                                                                                                                                    |
| `@livething/server/scheduled`       | The `scheduled()` capability.                                                                                                                                                                                                                         |
| `@livething/server/dedup`           | The `dedup()` capability.                                                                                                                                                                                                                             |
| `@livething/server/sequence`        | The `sequence()` capability.                                                                                                                                                                                                                          |
| `@livething/server/keepalive`       | The `keepalive()` capability.                                                                                                                                                                                                                         |
| `@livething/server/rate-limit`      | The `rateLimit()` capability.                                                                                                                                                                                                                         |
| `@livething/server/replay`          | Replay capability helpers.                                                                                                                                                                                                                            |
| `@livething/server/inbox`           | `inbox()` and `readReceipts()` capability helpers.                                                                                                                                                                                                    |
| `@livething/server/last-seen`       | The `lastSeen()` capability.                                                                                                                                                                                                                          |
| `@livething/server/streams`         | Stream capability helpers and stream types.                                                                                                                                                                                                           |
| `@livething/server/channels`        | The `channels()` capability and channel helpers.                                                                                                                                                                                                      |
| `@livething/server/tags`            | The `tags()` capability and tag helpers.                                                                                                                                                                                                              |
| `@livething/server/binary`          | The `binary()` capability, which turns binary messages on, and its `BinaryCapability` and `BinaryDeclarations` types.                                                                                                                                 |
| `@livething/server/plugins`         | Server plugin authoring helpers.                                                                                                                                                                                                                      |

## `@livething/server-node`

| Import                           | Use                                                                                                                                                               |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@livething/server-node`         | `setup`, and the `NodeSetup`, `NodeEndpointBinding`, `NodeServerEndpointOptions`, `NodeAdmin`, `NodeEndpointOptions`, `NodeWebSocketServer` and `Platform` types. |
| `@livething/server-node/binding` | The API for building a Node WebSocket integration for a framework.                                                                                                |
| `@livething/server-node/hono`    | The Hono integration.                                                                                                                                             |
| `@livething/server-node/fastify` | The Fastify integration.                                                                                                                                          |
| `@livething/server-node/h3`      | The H3 v2 integration.                                                                                                                                            |
| `@livething/server-node/h3/v1`   | The H3 v1 integration.                                                                                                                                            |

## `@livething/server-cloudflare`

| Import                         | Use                                                                                                                       |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------- |
| `@livething/server-cloudflare` | `bind`, and the `CloudflareDurableObjectClass`, `LiveThingDurableObjectInstance`, `CloudflareAdmin` and `Platform` types. |

Use the subpath for a capability in application code, for example `import { inbox } from '@livething/server/inbox'`. Importing from a package's internal `src` path is not part of the public API.
