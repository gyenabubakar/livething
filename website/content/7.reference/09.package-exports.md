WSKit keeps the main package imports small and exposes server and client capabilities through stable subpaths. The package names below are the public exports from each package's `package.json`.

## `@wskit/core`

| Import        | Use                                                                                                             |
| ------------- | --------------------------------------------------------------------------------------------------------------- |
| `@wskit/core` | Shared `WSKitError` definitions, built-in errors, `CloseCodes`, wire types, validators, and identifier helpers. |

## `@wskit/client`

| Import                      | Use                                                                                                                                            |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `@wskit/client`             | `client`, `connect`, client primitives, socket and contract types, `PrimitiveFactory`, `ServerRequestsOf`, `WireMessage`, and `WSKitEnvelope`. |
| `@wskit/client/errors`      | Client errors (`Timeout`, `Disconnected`, `Dropped`) and shared error helpers such as `WSKitError` and `Block`.                                |
| `@wskit/client/environment` | `environment`, `WebEnvironment`, and `ClientEnvironment`.                                                                                      |
| `@wskit/client/platform`    | Platform helpers and `PlatformOptions`.                                                                                                        |
| `@wskit/client/testing`     | `inject` and `injectChannel` for pushing test messages through the real client pipeline.                                                       |

`PrimitiveFactory` is the type used when declaring a client primitive dependency. `ServerRequestsOf<T>` extracts the server-request map from a contract; both are type-only exports from the main client entry point.

## `@wskit/server`

| Import                     | Use                                                                                                                                                |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@wskit/server`            | `define`, `emits`, `errors`, `translator`, `Translator`, `TranslatorFactory`, `InferClient`, shared server context types, and core server helpers. |
| `@wskit/server/adapters`   | Adapter types and the adapter factory.                                                                                                             |
| `@wskit/server/errors`     | Server error definitions and server-side error helpers.                                                                                            |
| `@wskit/server/requests`   | The `requests()` capability.                                                                                                                       |
| `@wskit/server/scheduled`  | The `scheduled()` capability.                                                                                                                      |
| `@wskit/server/dedup`      | The `dedup()` capability.                                                                                                                          |
| `@wskit/server/sequence`   | The `sequence()` capability.                                                                                                                       |
| `@wskit/server/keepalive`  | The `keepalive()` capability.                                                                                                                      |
| `@wskit/server/rate-limit` | The `rateLimit()` capability.                                                                                                                      |
| `@wskit/server/replay`     | Built-in and custom replay capability helpers.                                                                                                     |
| `@wskit/server/inbox`      | `inbox()` and `readReceipts()` capability helpers.                                                                                                 |
| `@wskit/server/last-seen`  | The `lastSeen()` capability.                                                                                                                       |
| `@wskit/server/streams`    | Stream capability helpers and stream types.                                                                                                        |
| `@wskit/server/channels`   | The `channels()` capability and channel helpers.                                                                                                   |
| `@wskit/server/tags`       | The `tags()` capability and tag helpers.                                                                                                           |
| `@wskit/server/intercepts` | The `intercepts()` capability and intercept helpers.                                                                                               |
| `@wskit/server/plugins`    | Server plugin authoring helpers.                                                                                                                   |

Use the subpath for a capability in application code, for example `import { inbox } from '@wskit/server/inbox'`. Importing from a package's internal `src` path is not part of the public API.
