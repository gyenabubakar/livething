LiveThing keeps the main package imports small and exposes server and client capabilities through stable subpaths. The import paths below are the public exports from each package's `package.json`. The Use column names the main exports of each path, and the types may not all be listed.

## `@livething/core`

| Import            | Use                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `@livething/core` | `error` and `namespaceError` to define errors, `LiveThingError`, the built-in errors, `CloseCodes`, the wire types and `decodeMessage` and `encodeMessage`, `WIRE_LIMITS`, `exceedsWireLimit`, the identifier checks `isValidLiveThingIdentifier` and `assertValidLiveThingIdentifier`, `LiveThingConfigError` with its helpers, `utf8ByteLength`, `encodeBase64` and `decodeBase64`, the token subprotocol helpers (`LIVETHING_SUBPROTOCOL`, `TOKEN_SUBPROTOCOL_PREFIX`, `tokenSubprotocols`, `isLiveThingSubprotocol`, `encodeBase64Url` and `decodeBase64Url`), and the binary frame helpers `encodeBinaryFrame`, `splitBinaryFrame`, `asUint8Array`, `BINARY_ENVELOPE_LIMIT` and `BINARY_HEADER_LENGTH`. |

## `@livething/client`

| Import                          | Use                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `@livething/client`             | `client`, `connect`, the transports `websocket` and `sse` (with the `TransportFactory`, `TransportName`, `Transport`, `TransportOpenOptions` and `TransportEvents` types for a [custom transport](/server/adapters/custom-transports)), client primitives (including `binary` and `uploads`), the `Upload`, `UploadOptions` and `UploadSource` types, socket and contract types (including `BinaryContract`, `BinaryOf`, `UploadsOf`, `BinaryMessaging`, `BinaryItem`, `BinaryAnswer` and `BinaryOptions`), `PrimitiveFactory`, `ServerRequestsOf`, `Message`, `WireFrame`, `LiveThingMetadata`, and `CloseCodes`. |
| `@livething/client/errors`      | Client errors (`Timeout`, `Disconnected`, `Dropped`, `StreamCorrupted`, `StreamOverflow`), `UploadAborted`, and shared error helpers such as `LiveThingError` and `Block`.                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `@livething/client/environment` | `environment`, `WebEnvironment`, and `ClientEnvironment`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `@livething/client/platform`    | Platform helpers and `PlatformOptions`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `@livething/client/testing`     | `inject`, `injectChannel`, `injectBinary` and `injectChannelBinary` for pushing test messages through the real client pipeline.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

`PrimitiveFactory` is the type used when declaring a client primitive dependency. `ServerRequestsOf<T>` extracts the server-request map from a contract; both are type-only exports from the main client entry point.

Use the subpath for a capability in application code, for example:

```typescript
// server/huddle-definition.ts
import { inbox } from '@livething/server/inbox'
```

Importing from a package's internal `src` path is not part of the public API.
