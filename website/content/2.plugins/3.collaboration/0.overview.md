::note
This plugin is coming soon. It does not ship yet, so this page has no code.
::

**Collaboration** will give you shared documents and typed shared state that many people edit at once:

- edits from different people never conflict, in text and in typed data;
- the state type comes from your server, and the server checks every change;
- undo and redo for each user;
- version history;
- anchors that stay on their words or items as people edit. Use them for highlights, bookmarks, or comments with the [Comments](/plugins/comments/overview) plugin;
- offline edits merge when the user reconnects.
