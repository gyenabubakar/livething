This plugin is coming soon. It does not ship yet, so this page has no code.
::

**Collaboration** will give you shared documents that many people edit at once:

- edits from different people never conflict;
- undo and redo for each user;
- comments stay on the right spot as people edit;
- offline edits merge when the user reconnects.
