A doc's `state`, `select()`, `status`, `access`, `locks` and awareness are LiveThing [`ReadableStore`s](/core/client/overview#reactive-stores), the same kind as `socket.state`. So the adapters from the [framework recipes](/core/recipes/framework-hooks/react) work as they are: `useStore` for React and Vue, `toStore` for Svelte, and `toSignal` for Solid. `change()` is a plain function you call from an event handler.

Each example shows one task of the board, and toggles it on click. An unchanged task is the same object in each new snapshot, so the component does not re-render when another task changes. In React, `select()` gives that; in Vue, Svelte and Solid, a derived value does, and it also follows a new `id`.

## React

```tsx [TaskRow.tsx]
import { useMemo } from 'react'
import { board } from './task-board'
import { useStore } from './use-store'

export function TaskRow({ id }: { id: string }) {
  const selected = useMemo(
    () => board.select((s) => s.tasks.find((t) => t.id === id)),
    [id],
  )
  const task = useStore(selected)

  function toggle() {
    board.change((d) => {
      const draft = d.tasks.find((t) => t.id === id)
      if (draft) draft.done = !draft.done
    })
  }

  return (
    <li onClick={toggle}>
      {task?.done ? '✓ ' : ''}
      {task?.title}
    </li>
  )
}
```

Make the `select()` store once per task with `useMemo`, not on every render. Open the board in a `useEffect` that returns its `close()`:

```ts
import { useEffect } from 'react'
import { showToast } from './huddle-ui'
import { board } from './task-board'

useEffect(() => {
  let mounted = true
  board.open().catch((error) => {
    if (mounted) showToast(String(error))
  })
  return () => {
    mounted = false
    board.close()
  }
}, [])
```

`open()` is counted, and the doc waits `closeDelayMs` after the last `close()`, so StrictMode's quick unmount and remount does not leave and join the doc again. When the component goes away before the doc synced, and `closeDelayMs` runs out before the sync, `open()` rejects because the doc was closed; `mounted` keeps that from showing as an error.

## Vue

```vue [TaskRow.vue]
<script setup lang="ts">
import { computed } from 'vue'
import { board } from './task-board'
import { useStore } from './useStore'

const props = defineProps<{ id: string }>()
const state = useStore(board.state)
const task = computed(() =>
  state.value.tasks.find((t) => t.id === props.id),
)

function toggle() {
  board.change((d) => {
    const draft = d.tasks.find((t) => t.id === props.id)
    if (draft) draft.done = !draft.done
  })
}
</script>

<template>
  <li @click="toggle">
    {{ task?.done ? '✓ ' : '' }}{{ task?.title }}
  </li>
</template>
```

`computed` gives back the same task object when another task changes, so the row does not update.

## Svelte

```svelte [TaskRow.svelte]
<script lang="ts">
  import { board } from './task-board'
  import { toStore } from './stores'

  let { id }: { id: string } = $props()
  const boardState = toStore(board.state)
  // Runs again when `id` changes; an unchanged task is the same object, so nothing re-renders.
  const task = $derived($boardState.tasks.find((t) => t.id === id))

  function toggle() {
    board.change((d) => {
      const draft = d.tasks.find((t) => t.id === id)
      if (draft) draft.done = !draft.done
    })
  }
</script>

<li onclick={toggle}>{task?.done ? '✓ ' : ''}{task?.title}</li>
```

## Solid

```tsx [TaskRow.tsx]
import { createMemo } from 'solid-js'
import { board } from './task-board'
import { toSignal } from './to-signal'

export function TaskRow(props: { id: string }) {
  const state = toSignal(board.state)
  const task = createMemo(() =>
    state()?.tasks.find((t) => t.id === props.id),
  )

  function toggle() {
    board.change((d) => {
      const draft = d.tasks.find((t) => t.id === props.id)
      if (draft) draft.done = !draft.done
    })
  }

  return (
    <li onClick={toggle}>
      {task()?.done ? '✓ ' : ''}
      {task()?.title}
    </li>
  )
}
```

## Lists

When you render the tasks, key each row by `board.keyOf(task)`. The key stays the same when the task moves, so the framework moves the row instead of rebuilding it:

```tsx [TaskList.tsx]
import { board } from './task-board'
import { useStore } from './use-store'

export function TaskList() {
  const state = useStore(board.state)

  return (
    <ul>
      {state.tasks.map((task) => (
        <li key={board.keyOf(task)}>{task.title}</li>
      ))}
    </ul>
  )
}
```
