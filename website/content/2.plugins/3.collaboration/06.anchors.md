An **anchor** says "these words" or "this item" in a doc, and it follows them as people edit. If someone types before the words, the anchor moves with them. If someone moves the task, the anchor stays on it. Use anchors for highlights, bookmarks, "jump to" links, and comments.

An anchor is plain JSON, so you can store it in your database or send it in a message, and turn it back into a place later.

## On some words

`anchor.text(path, { from, to })` anchors characters `from` to `to` (the end not included) of a `text()` or `richText()` field. The path is a function that picks the field:

```typescript [client/highlights.ts]
import { board } from './task-board'

// Highlight the first word of the first task's title.
const anchor = board.anchor.text((p) => p.tasks[0]?.title, {
  from: 0,
  to: 5,
})

board.anchor.watch(anchor).subscribe((place) => {
  if (!place) return console.info('the words were deleted')

  console.info(`"${place.text}" is now at ${place.from}-${place.to}`)
})
```

The range must hold at least one character, inside the text, or `anchor.text()` throws. `watch(anchor)` is a store of where the anchor is now: `{ from, to, text }`, or `null` once its words are deleted. For rich text, `from` and `to` count in the plain text that `state` shows, with each block on its own line.

## On an item

`anchor.item(path)` anchors one list item or record entry. The path picks it by where it is now, and the anchor then stays on the item itself, wherever it moves:

```typescript [client/bookmarks.ts]
import { board } from './task-board'

export function bookmarkTask(index: number) {
  const anchor = board.anchor.item((p) => p.tasks[index])

  return board.anchor.watch(anchor) // a store of { key, index } or null
}
```

The place is `{ key, index }`: the item's internal ID (the same as `keyOf()`), and its index in the list now, or `null` for a record entry. It is `null` once the item is deleted.

## Storing an anchor

```ts
const anchor = board.anchor.item((p) => p.tasks[0])
const saved = JSON.stringify(anchor) // store it anywhere
const place = board.anchor.watch(JSON.parse(saved)) // the same place
```

`watch()` takes either kind back from JSON.

## How anchors behave

- **Typing before or inside the words** moves or grows the range. Typing right at the start or the end of the range does not widen it.
- **Assigning text in `change()`** changes only the letters that differ, so an anchor on words that stayed keeps them. If some of its words changed, it shrinks to the characters the diff kept.
- **Rich text**: when an editor splits a paragraph (the user presses Enter inside the anchored words), it moves the words after the split into new text, and an anchor on those words resolves to `null`.
- **An item anchor survives moves**, and comes back when an undo brings the deleted item back, because the undo restores the same ID.
- **Restoring a version** keeps item IDs and the words that did not change, so most anchors stay ([Versions](/plugins/collaboration/versions)).
- `list.set(index, item)` keeps the item's ID, so an item anchor stays on it.

An anchor only names a place. It does not stop anyone from editing or deleting the words.
