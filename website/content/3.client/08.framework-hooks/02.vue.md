In Vue the pattern is a composable that holds a `ref`, updates it when the socket changes, and cleans up with `onScopeDispose`. Subscribing inside `onMounted` keeps it client-only, which is what you want under SSR (Nuxt).

## Connection state

```ts [useConnectionState.ts]
import { shallowRef, onMounted, onScopeDispose, readonly } from 'vue'
import { socket } from './socket'

export function useConnectionState() {
  const state = shallowRef(socket.getState())
  let off: (() => void) | undefined

  onMounted(() => {
    off = socket.subscribe(() => { state.value = socket.getState() })
  })
  onScopeDispose(() => off?.())

  return readonly(state)
}
```

```vue [StatusDot.vue]
<script setup lang="ts">
import { useConnectionState } from './useConnectionState'
const state = useConnectionState()
</script>

<template>
  <span :class="state === 'open' ? 'green' : 'grey'">{{ state }}</span>
</template>
```

`onScopeDispose` runs when the component (or effect scope) is torn down, so the subscription is always released.

## Incoming events

`socket.on(event, handler)` returns an unsubscribe — store it and release it on dispose. Type the composable over the contract's incoming events so the event name is checked and the payload is inferred, no cast:

```ts [useIncoming.ts]
import { shallowRef, onMounted, onScopeDispose } from 'vue'
import { socket } from './socket'
import type { ChatSocket } from '../server/chat'

type Incoming = ChatSocket['incoming']

export function useIncoming<E extends keyof Incoming & string>(event: E) {
  const data = shallowRef<Incoming[E]>()
  let off: (() => void) | undefined

  onMounted(() => {
    off = socket.on(event, (d) => { data.value = d })
  })
  onScopeDispose(() => off?.())

  return data
}
```

```vue [Notifications.vue]
<script setup lang="ts">
import { useIncoming } from './useIncoming'
const note = useIncoming('notification') // ShallowRef<{ title: string } | undefined> — inferred
</script>

<template>
  <Toast v-if="note">{{ note.title }}</Toast>
</template>
```

## Requests

A request is an async call; expose its result and error as refs:

```ts [useProfile.ts]
import { shallowRef, watchEffect } from 'vue'
import { socket } from './socket'

export function useProfile(id: () => string) {
  const profile = shallowRef<Profile>()
  const error = shallowRef<unknown>()

  watchEffect((onCleanup) => {
    let active = true
    onCleanup(() => { active = false })
    socket
      .request('get-profile', { id: id() })
      .then((p) => active && (profile.value = p))
      .catch((e) => active && (error.value = e))
  })

  return { profile, error }
}
```

`watchEffect` re-runs when `id()` changes, and the `active` flag drops a stale response — the Vue equivalent of React's cleanup guard.

## Connection quality

With [`keepalive()`](/client/primitives/keepalive), subscribe with `onQualityChange` and read `getQuality`, the same way as connection state:

```ts [useQuality.ts]
import { shallowRef, onMounted, onScopeDispose } from 'vue'
import { socket } from './socket'

export function useQuality() {
  const quality = shallowRef(socket.getQuality())
  let off: (() => void) | undefined

  onMounted(() => {
    off = socket.onQualityChange(() => { quality.value = socket.getQuality() })
  })
  onScopeDispose(() => off?.())

  return quality
}
```

## Connecting and SSR

Open the socket once near the root — in your root component's `onMounted`, or a small client plugin — so it never runs during SSR:

```ts [app.client.ts]
import { socket } from './socket'

socket.connect()
```

Because the composables above subscribe in `onMounted` and start from `socket.getState()` (which is `'closed'` before connecting), they render the same on the server and the first client paint, avoiding a hydration mismatch. See [SSR Safety](/client/connecting/ssr-safety) for the full picture.
