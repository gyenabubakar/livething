A custom transport has two halves: a client transport, which you list in `connect()`, and a server transport, which you list in the adapter's `bind()`. This page covers the client half. The server half, and why LiveThing has no built-in long polling, are on the server [Custom Transports](/runtimes/transports/custom-transports) page.

The long-polling transport on this page follows these wire rules. The client sends every request with a `LiveThing-Transport: long-polling` header. The first `GET` opens the connection. Each later `GET` carries the secret from `__connected__`, and waits up to 20 seconds for frames. A `POST` carries the client's frames, or its close. The [server page](/runtimes/transports/custom-transports#a-complete-long-polling-transport) has the full description.

## The client side

A client transport is a `TransportFactory`: a `name` and an `open()` that starts one connection. The socket calls `open()` once for each try, with the URL, the `token` of this try, and the events to report:

| Event                           | When to call it                                                                                                                          |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `open()`                        | The server answered. The socket then waits for the `__connected__` frame.                                                                |
| `message(data)`                 | A frame arrived: a string, or an `ArrayBuffer` for binary.                                                                               |
| `close(code, reason, wasClean)` | The connection ended. Call it once. Use `1006` when it failed with no close code.                                                        |
| `error(event)`                  | Something failed. A `close` follows.                                                                                                     |
| `stable()`                      | Optional. The connection has carried data both ways, so [`reconnection()`](/client/primitives/reconnection) may forget its failed tries. |
| `unusable()`                    | Optional. The connection opened but cannot carry data. The socket skips this transport for 5 minutes. A `close` follows.                 |

The socket treats your transport like the built-in ones. [Failover](/client/transports/overview#failover) moves on from it when it closes with `1006` before `__connected__`, a close with a code is final, and `socket.transport` shows its `name`.

`open()` returns a `Transport`:

| Member                  | What it does                                                                                                    |
| ----------------------- | --------------------------------------------------------------------------------------------------------------- |
| `name`                  | The same name as the factory.                                                                                   |
| `protocol`              | The subprotocol the server picked, or `''`.                                                                     |
| `webSocket`             | `null`. Only the WebSocket transport has one.                                                                   |
| `reportsStable`         | `true` when the transport calls `stable()` itself. When `false`, the connection counts as stable when it opens. |
| `isOpen()`              | Whether the connection is open.                                                                                 |
| `send(data)`            | Send a frame: a string, or a `Uint8Array` for binary. Keep the order.                                           |
| `sendControl(frame)`    | Send `'ping'` or `'pong'`.                                                                                      |
| `bufferedAmount()`      | The bytes waiting to be sent, for `socket.drain()`.                                                             |
| `close(code, reason)`   | Close the connection. The `close` event still fires.                                                            |
| `dispose(code, reason)` | Stop all events, then close. The socket calls it when it drops this try.                                        |

List the factory in `connect()`. The URL is the same for every transport:

```ts [client/connect-huddle.ts]
import { connect, http, websocket } from '@livething/client'
import { longPolling } from './long-polling'

const huddleConnection = connect('https://huddle.example/huddle', {
  transports: [websocket(), http(), longPolling()],
})
```

## A complete long-polling transport

The client side polls in a loop and sends its frames in order, one `POST` after another:

```ts [client/long-polling.ts]
import type {
  Transport,
  TransportFactory,
  TransportOpenOptions,
} from '@livething/client'

interface CloseInfo {
  code: number
  reason: string
}

interface PollAnswer {
  frames: string[]
  close: CloseInfo | null
}

export function longPolling(): TransportFactory {
  return { name: 'long-polling', open: openLongPolling }
}

function openLongPolling(options: TransportOpenOptions): Transport {
  const url = options.url.replace(/^ws/i, 'http')
  const abort = new AbortController()
  let state: 'connecting' | 'open' | 'closed' = 'connecting'
  let muted = false
  let secret: string | null = null

  let sending = Promise.resolve()

  function headers(): Record<string, string> {
    if (secret !== null) {
      return {
        'LiveThing-Transport': 'long-polling',
        'LiveThing-Secret': secret,
      }
    }

    return {
      'LiveThing-Transport': 'long-polling',
      ...(options.token === null
        ? {}
        : { Authorization: `Bearer ${options.token}` }),
    }
  }

  function end(info: CloseInfo, wasClean: boolean) {
    if (state === 'closed') return

    state = 'closed'
    abort.abort()
    if (!muted) options.events.close(info.code, info.reason, wasClean)
  }

  function read(frame: string) {
    if (secret === null && frame.startsWith('["__connected__"')) {
      secret = (JSON.parse(frame) as [string, { secret: string }])[1]
        .secret
    }

    if (!muted) options.events.message(frame)
  }

  async function pollLoop() {
    try {
      while (state !== 'closed') {
        const response = await fetch(url, {
          headers: headers(),
          signal: abort.signal,
        })
        if (!response.ok) {
          end(
            { code: 1006, reason: `HTTP ${response.status}` },
            false,
          )
          return
        }

        if (state === 'connecting') {
          state = 'open'
          if (!muted) options.events.open()
        }

        const answer = (await response.json()) as PollAnswer
        for (const frame of answer.frames) read(frame)

        if (answer.close) end(answer.close, true)
      }
    } catch (error) {
      if (state === 'closed') return

      if (!muted) options.events.error(error)
      end({ code: 1006, reason: '' }, false)
    }
  }

  function post(message: { frames?: string[]; close?: CloseInfo }) {
    sending = sending.then(async () => {
      try {
        const response = await fetch(url, {
          method: 'POST',
          headers: {
            ...headers(),
            'Content-Type': 'application/json',
          },
          body: JSON.stringify(message),
        })
        if (!response.ok) {
          end({ code: 1006, reason: 'POST failed' }, false)
        }
      } catch {
        end({ code: 1006, reason: 'POST failed' }, false)
      }
    })
  }

  function close(code = 1000, reason = '') {
    if (secret !== null && state === 'open') {
      post({ close: { code, reason } })
    }

    end({ code, reason }, true)
  }

  void pollLoop()

  return {
    name: 'long-polling',
    protocol: '',
    webSocket: null,
    reportsStable: false,
    isOpen: () => state === 'open',
    send(data) {
      if (typeof data !== 'string') {
        throw new Error('The long-polling transport sends text only.')
      }

      post({ frames: [data] })
    },
    sendControl: (frame) => post({ frames: [frame] }),
    bufferedAmount: () => 0,
    close,
    dispose(code, reason) {
      muted = true
      close(code, reason)
    },
  }
}
```

To carry [binary messages](/client/primitives/binary), the server sends a `bytes` frame as base64 text with a mark, as [`http()` does](/learn/wire-protocol#over-http). Turn it back into an `ArrayBuffer` on the client before `message()`.
