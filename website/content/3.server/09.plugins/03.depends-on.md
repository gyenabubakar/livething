Some engines are **host-owned**: `dedup`, `sequence`, `keepalive`, `persistence`, `rateLimit`, and the whole `replay` family — built-in `replay.history()` / `replay.snapshot()` **and** `replay.custom()`. They are global to the whole server, so a plugin can never list one in its scoped [`define`](/server/plugins/authoring) — doing so is a compile error. A plugin that *needs* one declares a prerequisite instead, and the host must satisfy it.

```typescript [host-only.ts]
const h = define({
  scoped: true,
  capabilities: [
    resumableStream(),   // OK — a plugin can own its own durable streams
    // persistence(),    // compile error: host-owned, a plugin can't list it
  ],
})
```

## Auto-derived requirements

The durable streams above *need* persistence to work, but the plugin does not — and cannot — list it. That requirement is **auto-derived**: WSKit reads it off the plugin's own streams and passes it up to the host as a dependency. The host must list `persistence()`, or its `assemble` fails with a clear error. (This is the requirement mechanism from [Capabilities](/server/define/capabilities), applied across the plugin boundary.)

::note
"Plugin-safe" is exactly "every capability except the host-owned engines listed above." Behavior capabilities a plugin *can* own itself — `requests`, `channels`, the stream kinds, `emits`, `errors`, `tags`, `intercepts` — are all fine in a scoped list. Note `base.replay` is not among them: even `replay.custom()` is host-owned, so a plugin cannot register its own custom replay strategy.
::

## Stating a prerequisite explicitly

Auto-derivation covers anything the plugin's own capabilities imply. When a plugin's *code* needs a host capability that nothing in its config implies — it reads a value only `requests()` provides, say — state it directly with `dependsOn`, passing the host capability factory:

```typescript [depends-on.ts]
import { plugin } from '@wskit/server/plugin'
import { persistence } from '@wskit/server/persistence'

export const Durable = plugin('acme:durable', {
  handler: h.assemble(/* ... */),
  dependsOn: [persistence],   // the host must list persistence()
})
```

A missing prerequisite is a build error that names what to add, the same way a [capability requirement](/server/define/capabilities) does for a top-level server. Only host capability **factories** are accepted here — passing a plugin factory is a compile error.
