`@wskit/server-node` runs a WSKit server definition on [Node.js](https://nodejs.org). The definition you write — `define`, capabilities, handlers, `assemble` — is identical to every other adapter; only the entry file that hands your definition to the adapter changes.

For the shared server-definition code in full, see the [Cloudflare adapter](/server/adapters/cloudflare) worked example — everything above the adapter entry is the same on Node.js. For what an adapter does under the hood, see [Custom adapters](/server/adapters/custom-adapters).
