A **client request** is a question from a client that waits for your server's answer. `clientRequests()` enables `base.request(...)` and channel `.request(...)` handlers.

Import it from `@wskit/server/client-requests`:

```typescript [server.ts]
import { clientRequests } from '@wskit/server/client-requests'
```

## Client-to-server requests

List `clientRequests()`, then register a handler with `base.request(event, { input, run })`:

```typescript [server.ts]
import { define, t } from '@wskit/server'
import { clientRequests } from '@wskit/server/client-requests'
import * as v from 'valibot'

const base = define({
  capabilities: [clientRequests()],
})

export const handleGetUser = base.request('get-user', {
  input: v.object({ id: v.string() }),
  run(_ctx, input) {
    return { id: input.id, name: 'Ada' }
  },
})
```

::note
`base.request(...)` creates a handler value. Include it in `base.assemble({ handlers: [...] })` for it to run and enter `InferClient`.
::

A request is like `base.on`, but the client awaits a reply. The reply type is inferred from what `run` returns — here `{ id: string; name: string }`.

::note
If `run` returns nothing — no `return`, or `null` or `undefined` — the client's request settles as a **void acknowledgement**. To fail a request, throw. Model a nullable answer as an object such as `{ value: null }`, because a bare `null` is the void acknowledgement.
::

For handler details — `run`, explicit `respond`, acknowledgements, and rejection — see [base.request](/server/handlers/request).

### The contract slice

`clientRequests()` fills the client contract's `clientRequests` key. Each entry pairs the `payload` the client sends with the `response` it gets back:

```typescript [user-socket.ts]
interface UserSocket {
  clientRequests: {
    'get-user': {
      payload: { id: string }
      response: { id: string; name: string }
    }
  }
}
```

Channel handlers use the same capability. With `clientRequests()` listed at the root, `channel.request(event, { input, run })` handles a request from a member and sends its return value back to that member.
