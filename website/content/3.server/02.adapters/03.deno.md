LiveThing has no Deno adapter. Deno can run most Node.js code, so the [Node.js adapter](/server/adapters/node), `@livething/server-node`, runs on Deno with one change: you give it your own SQL storage. Your definition and your `node:http` server stay the same.

::warning
Deno is not a supported runtime. LiveThing's CI runs the Node.js adapter on Node.js only. We ran LiveThing's end-to-end tests once on Deno 2.9, with a `node:http` server and the storage on this page, over WebSocket and server-sent events, and they passed. A later Deno or LiveThing release can still break it. The [Node frameworks](/server/adapters/node#frameworks) were not tried on Deno.
::

## Install

Install the packages from npm with `deno add`:

```bash [deno]
deno add npm:@livething/server npm:@livething/server-node npm:@livething/core
```

## Storage

On Node.js, the adapter stores `ctx.sql` and `ctx.kv` in SQLite through [better-sqlite3](https://github.com/WiseLibs/better-sqlite3). Deno cannot load better-sqlite3: it is a native module built on an older Node API that Deno does not have. When the adapter opens its default database on Deno, `bind()` throws.

Deno has its own SQLite in the `node:sqlite` module. Build the `sql` and `kv` providers on it, and pass both to `bind()`. The adapter then never loads better-sqlite3. It is still installed with the adapter, but it is never used.

```ts [server/huddle-storage.ts]
import { DatabaseSync } from 'node:sqlite'
import { deserialize, serialize } from 'node:v8'
import {
  rejectAsyncTransactionCallback,
  rejectAsyncTransactionResult,
} from '@livething/server/adapters'
import type {
  KVProvider,
  SQLProvider,
  SqlResult,
} from '@livething/server/adapters'

export function openHuddleStorage(path: string) {
  const database = new DatabaseSync(path)
  database.exec('PRAGMA foreign_keys = ON')
  let depth = 0

  const sql: SQLProvider = {
    limits: {
      maxBoundParams: 32_766,
      maxStatementBytes: 1_000_000_000,
      maxValueBytes: 1_000_000_000,
    },

    exec<TRow>(query: string, ...params: unknown[]): SqlResult<TRow> {
      if (query.trim() === '') return sqlResult<TRow>([], [])

      const statement = database.prepare(query)
      if (statement.columns().length === 0) {
        // prepare() reads only the first statement of a batch.
        if (params.length === 0) database.exec(query)
        else statement.run(...(params as never[]))

        return sqlResult<TRow>([], [])
      }

      statement.setReturnArrays(true)
      const raw = statement.all(
        ...(params as never[]),
      ) as unknown as unknown[][]
      const names = statement.columns().map((column) => column.name)
      const rows = raw.map((values) =>
        Object.fromEntries(
          names.map((name, index) => [name, values[index]]),
        ),
      )

      return sqlResult(rows as TRow[], raw)
    },

    transaction<T>(fn: () => T): T {
      rejectAsyncTransactionCallback(fn)
      const savepoint = `huddle_${depth}`
      database.exec(`SAVEPOINT ${savepoint}`)
      depth += 1
      try {
        const value = fn()
        rejectAsyncTransactionResult(value)
        database.exec(`RELEASE ${savepoint}`)

        return value
      } catch (error) {
        database.exec(
          `ROLLBACK TO ${savepoint}; RELEASE ${savepoint}`,
        )
        throw error
      } finally {
        depth -= 1
      }
    },
  }

  database.exec(`CREATE TABLE IF NOT EXISTS huddle_kv (
    key TEXT PRIMARY KEY,
    value BLOB NOT NULL,
    expires_at INTEGER
  )`)

  function isFresh(key: string, expiresAt: number | null): boolean {
    if (expiresAt === null || expiresAt > Date.now()) return true

    database.prepare('DELETE FROM huddle_kv WHERE key = ?').run(key)
    return false
  }

  const kv: KVProvider = {
    async get(key) {
      const row = database
        .prepare(
          'SELECT value, expires_at FROM huddle_kv WHERE key = ?',
        )
        .get(key) as
        | { value: Uint8Array; expires_at: number | null }
        | undefined

      if (!row || !isFresh(key, row.expires_at)) return undefined

      return deserialize(row.value)
    },

    async set(key, value, options) {
      const expiresAt = options?.ttl ? Date.now() + options.ttl : null
      database
        .prepare(
          `INSERT INTO huddle_kv (key, value, expires_at) VALUES (?, ?, ?)
           ON CONFLICT(key) DO UPDATE
           SET value = excluded.value, expires_at = excluded.expires_at`,
        )
        .run(key, serialize(value), expiresAt)
    },

    async delete(key) {
      database.prepare('DELETE FROM huddle_kv WHERE key = ?').run(key)
    },

    async list(prefix = '') {
      const pattern = `${prefix.replace(/[*?[]/g, (char) => `[${char}]`)}*`
      const rows = database
        .prepare(
          'SELECT key, expires_at FROM huddle_kv WHERE key GLOB ?',
        )
        .all(pattern) as { key: string; expires_at: number | null }[]

      return rows
        .filter((row) => isFresh(row.key, row.expires_at))
        .map((row) => row.key)
    },
  }

  return { sql, kv, close: () => database.close() }
}

function sqlResult<TRow>(
  rows: TRow[],
  raw: unknown[][],
): SqlResult<TRow> {
  let readBy: string | undefined
  function read<T>(reader: string, value: () => T): T {
    if (readBy) {
      throw new Error(
        `sql.exec() result already consumed by .${readBy}()`,
      )
    }

    readBy = reader
    return value()
  }

  return {
    toArray: () => read('toArray', () => rows),
    raw: () => read('raw', () => raw),
    one: () =>
      read('one', () => {
        if (rows.length > 1) {
          throw new Error('sql.one() expected at most one row')
        }

        return rows[0] ?? null
      }),
  }
}
```

The providers follow the rules for a [custom SQL provider](/server/adapters/custom-adapters#the-transaction-contract): `transaction` nests with savepoints, rolls back when its callback throws, and refuses an async callback. A result can be read [only once](/server/context-and-storage/sql-and-kv), as on Node.js. `kv` keeps its keys in a table of the same database, and drops a key when its TTL has passed.

## The server

The entry file is the [node:http](/server/adapters/node#nodehttp) setup from the Node.js page, with two changes. The `sql` and `kv` options of `bind()` come from the storage above. And local imports end in `.ts`, because Deno does not guess file extensions. LiveThing does not close a database that you pass in, so close it after `shutdown()`.

```ts [huddle-server.ts]
import { createServer } from 'node:http'
import { setup } from '@livething/server-node'
import { huddle } from './server/huddle-definition.ts'
import { openHuddleStorage } from './server/huddle-storage.ts'

const huddleStorage = openHuddleStorage('./data/huddle.sqlite')
const { bind, ready, shutdown } = setup()
const huddleEndpoint = bind(huddle, {
  sql: huddleStorage.sql,
  kv: huddleStorage.kv,
})

const app = createServer((request, response) => {
  response.statusCode = 404
  response.end()
})

app.on('upgrade', (request, socket, head) => {
  const url = new URL(
    request.url ?? '/',
    `http://${request.headers.host}`,
  )

  if (url.pathname === '/huddle') {
    huddleEndpoint.upgrade(request, socket, head)
    return
  }

  socket.destroy()
})

await ready()
app.listen(3000)

process.once('SIGTERM', async () => {
  await shutdown()
  huddleStorage.close()
  app.close()
})
```

Run it with the permissions it needs: the network for the server, and the file system for the database.

```bash [deno]
deno run --allow-net --allow-read --allow-write --allow-env huddle-server.ts
```

Everything else on the [Node.js page](/server/adapters/node) applies: the options of `bind()`, server-sent events with `sse()` and `huddleEndpoint.handle`, the admin API, and shutdown. Like Node.js, Deno does not support hibernation.
