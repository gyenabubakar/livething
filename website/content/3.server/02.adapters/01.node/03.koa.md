Koa handles normal HTTP requests. Its middleware does not receive WebSocket upgrades, so bind WSKit to the Node server created with `app.callback()`.

```bash [pnpm]
pnpm add @wskit/server @wskit/server-node @wskit/core koa
```

```ts [koa.ts]
import { createServer } from 'node:http'
import { setup } from '@wskit/server-node'
import Koa from 'koa'
import { chatHandler } from './handler'

const app = new Koa()
app.use(async (context, next) => {
  if (context.path === '/health') {
    context.body = { ok: true }
    return
  }

  await next()
})

const httpServer = createServer(app.callback())
const { bind, ready } = setup()
const chat = bind(chatHandler, { sql: './data/chat.sqlite' })

httpServer.on('upgrade', (request, socket, head) => {
  if (
    new URL(request.url ?? '/', 'http://localhost').pathname ===
    '/ws/chat'
  ) {
    chat.upgrade(request, socket, head)
    return
  }

  socket.destroy()
})

await ready()
httpServer.listen(3000)
```

Koa route parameters and middleware do not run for an upgrade. Match the WebSocket path in this listener. For framework-owned WebSocket routes, use Hono, Fastify, or H3.

The adapter config, client-IP setup, storage, admin API, and shutdown behavior are the same as [node:http](/server/adapters/node/node-http).
