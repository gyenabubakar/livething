Express handles normal HTTP routes. It does not route WebSocket upgrades through Express middleware, so bind WSKit to the Node server that hosts the Express app.

```bash [pnpm]
pnpm add @wskit/server @wskit/server-node @wskit/core express
```

```ts [express.ts]
import { createServer } from 'node:http'
import { setup } from '@wskit/server-node'
import express from 'express'
import { chatHandler } from './handler'

const app = express()
app.get('/health', (_request, response) =>
  response.json({ ok: true }),
)

const httpServer = createServer(app)
const { bind, ready } = setup()
const chat = bind(chatHandler, { sql: './data/chat.sqlite' })

httpServer.on('upgrade', (request, socket, head) => {
  if (
    new URL(request.url ?? '/', 'http://localhost').pathname ===
    '/ws/chat'
  ) {
    chat.upgrade(request, socket, head)
    return
  }

  socket.destroy()
})

await ready()
httpServer.listen(3000)
```

Express route parameters and middleware do not run for an upgrade. Match the WebSocket path in this listener. For framework-owned WebSocket routes, use Hono, Fastify, or H3.

The adapter config, client-IP setup, storage, admin API, and shutdown behavior are the same as [node:http](/server/adapters/node/node-http).
