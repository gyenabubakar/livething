`@livething/server-bun` runs a LiveThing server definition on [Bun](https://bun.sh). The definition you write — `server`, capabilities, handlers, `assemble` — is identical to every other adapter; only the entry file that hands your definition to the adapter changes.

For the shared server-definition code in full, see the [Cloudflare adapter](/server/adapters/cloudflare) worked example — everything above the adapter entry is the same on Bun. For what an adapter does under the hood, see [Custom adapters](/server/adapters/custom-adapters).
