`@livething/server-deno` runs a LiveThing server definition on [Deno](https://deno.com). You write the definition with `server`, capabilities, handlers, and `assemble`, and this code is the same for every adapter. Only the entry file changes. The entry file is the small file that passes your definition to the adapter.

To see a full server definition, read the [Cloudflare adapter](/server/adapters/cloudflare) example. The `server/definition.ts` file in that example works on Deno with no changes. Only the Cloudflare files after it are different on Deno. To learn what an adapter does internally, see [Custom adapters](/server/adapters/custom-adapters).
