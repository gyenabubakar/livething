The client never touches `window`, `document`, `navigator`, or `WebSocket` at import time — or when you call `client(...)`. Those browser globals are read lazily, inside `connect()`. So you can import `@wskit/client` and create a socket in a server-rendered module — Next.js, Nuxt, SvelteKit, TanStack Start — and nothing happens until you actually connect, in the browser.

```typescript [socket.ts]
import { client, connect } from '@wskit/client'
import type { MySocket } from './socket-types'

// Safe at module scope, including during SSR / on Node — this opens nothing.
export const socket = client<MySocket>()(connect('wss://example.com/ws'))
```

## Connect in the browser

Creating the socket is safe anywhere; **connecting** is the browser-only step. Call `socket.connect()` from a mount hook or effect — somewhere that only runs on the client:

::code-group

```tsx [React]
import { useEffect } from 'react'
import { socket } from './socket'

function App() {
  // useEffect only runs in the browser — the right place to connect.
  useEffect(() => {
    socket.connect()
    return () => socket.disconnect()
  }, [])
  // ...
}
```

```svelte [Svelte]
<script>
  import { onMount } from 'svelte'
  import { socket } from './socket'

  // onMount only runs in the browser — the right place to connect.
  onMount(() => {
    socket.connect()
    return () => socket.disconnect()
  })
</script>
```

```vue [Vue]
<script setup lang="ts">
import { onBeforeUnmount, onMounted } from 'vue'
import { socket } from './socket'

onMounted(() => socket.connect())
onBeforeUnmount(() => socket.disconnect())
</script>
```

::

If you're on a lazy socket (`connect(url, { lazy: true })`), you don't even call `connect()` yourself — the first `on()` or `send()` opens it. Just make sure that first use happens in the browser, not during render.

## Platform signals are SSR-safe too

The browser environment you'd pass to [`platform()`](/client/platform/environments), `WebEnvironment`, is lazy in the same way: it reads `document` and `navigator` inside its subscribe calls, never at import time, and where those globals are absent (SSR, Node, a non-DOM runtime) it simply reports no signals. So declaring `platform({ environment: WebEnvironment })` at module scope is safe — it starts watching for visibility and network changes only once the socket is live in the browser.

## The one rule

Create the socket wherever you like; just don't **connect** during server render. A lazy first `on()`/`send()` or an explicit `connect()` belongs in a browser-only path — a mount hook, an effect, an event handler. Everything else about the socket is inert until then.
