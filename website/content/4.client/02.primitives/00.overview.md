A **primitive** is a feature you add to the socket by passing it to `client()`. Channels, request/response, streaming, reconnection, buffering — they're all primitives. You include the ones you need and nothing else: a primitive you don't pass isn't on the socket, and its code isn't in your bundle.

```typescript [app.ts]
import {
  channels,
  client,
  clientRequests,
  connect,
  reconnection,
} from '@wskit/client'
import type { MySocket } from './socket-types'

const socket = client<MySocket>()(
  connect('wss://example.com/ws'),
  channels(),
  clientRequests(),
  reconnection({ maxAttempts: Infinity }),
)
```

Everything is flat — no wrapper, no plugin object. Each primitive is a function you call and pass in.

## How they fit together

A few rules govern how primitives combine, all enforced when you build the socket:

- **Order doesn't matter.** Primitives are sorted by their dependencies before they run, so you can list them in any order. (If two ever formed a dependency cycle, `client()` throws at build.)
- **Register each at most once.** Passing the same primitive twice throws — the one exception is [`intercept()`](/client/primitives/intercept), which you can add several times; they run in the order you list them.
- **Some depend on others.** [`replay()`](/client/primitives/replay) needs [`dedup()`](/client/primitives/dedup), for example. Miss a dependency and `client()` throws with a message naming the one to add (`[wskit] replay requires dedup. Register dedup() in client.`).
- **The contract drives the types.** A primitive's methods are typed from your contract. Add `channels()` and `socket.channel(...)` is typed from your `channels`; add `stream()` and `socket.stream(...)` is typed from your `streams`.

If your contract declares a key but you forgot its primitive, the method is still on the socket as a non-callable stub whose type spells out the fix — so `socket.channel(...)` without `channels()` fails on the call with a message telling you to add `channels()`, rather than a confusing "property does not exist."

## The primitives

| Primitive                                                | Adds to the socket                         | Key options (defaults)                                               |
| -------------------------------------------------------- | ------------------------------------------ | -------------------------------------------------------------------- |
| [`channels()`](/client/primitives/channels)              | `socket.channel(...)`                      | `ttl`                                                                |
| [`clientRequests()`](/client/primitives/client-requests) | `socket.request(...)`                      | `timeout` (`10_000`)                                                 |
| [`serverRequests()`](/client/primitives/server-requests) | `socket.onRequest(...)`                    | —                                                                    |
| [`stream()`](/client/primitives/stream)                  | `socket.stream/onStream/resumeStream`      | `timeout` (`30_000`), `nudgeTimeout` (`10_000`)                      |
| [`replay()`](/client/primitives/replay)                  | — (catch-up on reconnect)                  | needs `dedup()`                                                      |
| [`dedup()`](/client/primitives/dedup)                    | — (drops duplicates)                       | `windowMs` (`60_000`)                                                |
| [`reconnection()`](/client/primitives/reconnection)      | `socket.reconnection` store                | `maxAttempts` (`10`), `maxDelay` (`30_000`), `networkAware` (`true`) |
| [`buffering()`](/client/primitives/buffering)            | — (queue while offline)                    | `enabled` (`false`), `maxSize` (`50`), `ttl`, `flushInterval` (`0`)  |
| [`keepalive()`](/client/primitives/keepalive)            | `socket.quality` · `socket.latency` stores | `interval` (`30_000`), `maxMissedPongs` (`2`)                        |
| [`quality()`](/client/primitives/quality)                | — (sets quality cut-offs)                  | `thresholds`                                                         |
| [`query()`](/client/primitives/query)                    | — (adds URL params)                        | a params function                                                    |
| [`intercept()`](/client/primitives/intercept)            | — (filter/transform incoming)              | an interceptor function                                              |
| [`debug()`](/client/primitives/debug)                    | — (console logging)                        | a boolean                                                            |

The dash in "adds to the socket" means the primitive works through the message pipeline and lifecycle rather than exposing a method — it changes behaviour, not the API surface.

::note
**Plugins** are the third-party version of primitives — reusable features you (or a package) author with `plugin()`. They hook into the same pipeline but reach their API through `Plugin.use(socket)` instead of adding socket methods. See [Plugins](/client/plugins/overview).
::
