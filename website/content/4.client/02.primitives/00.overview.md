A **primitive** is a feature you add to the socket by passing it to `client()`. Channels, request/response, streaming, reconnection and buffering are all primitives. You include only the ones you need. A primitive you don't pass is not on the socket, and its code is not in your bundle (the JavaScript file your app ships to users).

```typescript [client/socket.ts]
import {
  channels,
  client,
  clientRequests,
  connect,
  reconnection,
} from '@livething/client'
import type { HuddleSocket } from '@monorepo/server/huddle-definition'

export const socket = client<HuddleSocket>()(
  connect('wss://example.com/huddle'),
  channels(),
  clientRequests(),
  reconnection({ maxAttempts: Infinity }),
)
```

Each primitive is a function. You call it and pass the result straight to `client()`. There is no wrapper object and no extra setup step.

## How they fit together

`client()` checks these rules when it builds the socket:

- **Order doesn't matter.** Some primitives must run after others. `client()` sorts them by these dependencies before they run, so you can list them in any order. If two primitives ever depended on each other in a loop (a dependency cycle), `client()` would throw an error.
- **Register each primitive at most once.** If you pass the same primitive twice, `client()` throws. The one exception is [`intercept()`](/client/primitives/intercept). You can add it several times, and the interceptors run in the order you list them.
- **Some primitives need others.** For example, [`replay()`](/client/primitives/replay) needs [`dedup()`](/client/primitives/dedup). If a needed primitive is missing, `client()` throws an error that names it: `[livething] replay requires dedup. Register dedup() in client.`
- **The contract drives the types.** Your contract is the type that lists your app's events. A primitive's methods get their types from it. Add `channels()`, and `socket.channel(...)` is typed from the contract's `channels`. Add `stream()`, and `socket.stream(...)` is typed from the contract's `streams`.

Sometimes your contract declares a section but you forget its primitive. The method is then still on the socket, but as a stub: a property that TypeScript will not let you call. Its type holds a message that tells you what to add. For example, without `channels()`, the call `socket.channel(...)` fails to compile with a message telling you to add `channels()`. You get this clear hint instead of a general "property does not exist" error.

## The primitives

| Primitive                                                | Adds to the socket                                          | Key options (defaults)                                               |
| -------------------------------------------------------- | ----------------------------------------------------------- | -------------------------------------------------------------------- |
| [`channels()`](/client/primitives/channels)              | `socket.channel(...)`                                       | `ttl`                                                                |
| [`clientRequests()`](/client/primitives/client-requests) | `socket.request(...)`                                       | `timeout` (`10_000`)                                                 |
| [`serverRequests()`](/client/primitives/server-requests) | `socket.onRequest(...)`                                     | none                                                                 |
| [`stream()`](/client/primitives/stream)                  | `socket.stream/onStream/continueStream`                     | `timeout` (`30_000`), `nudgeTimeout` (`10_000`)                      |
| [`replay()`](/client/primitives/replay)                  | — (catches up on missed messages after a reconnect)         | needs `dedup()`                                                      |
| [`inbox()`](/client/primitives/inbox)                    | `receivers`, `onReceived`, `receiversOf` on a channel       | `timeout` (`10_000`), needs `dedup()`                                |
| [`readReceipts()`](/client/primitives/read-receipts)     | `readers`, `onRead`, `readersOf`, `markAsRead` on a channel | `timeout` (`10_000`)                                                 |
| [`gaps()`](/client/primitives/gaps)                      | `socket.onGap`, `channel.onGap`                             | none                                                                 |
| [`dedup()`](/client/primitives/dedup)                    | — (drops duplicate messages)                                | `windowMs` (`60_000`)                                                |
| [`reconnection()`](/client/primitives/reconnection)      | `socket.reconnection` store                                 | `maxAttempts` (`10`), `maxDelay` (`30_000`), `networkAware` (`true`) |
| [`buffering()`](/client/primitives/buffering)            | — (queues messages while offline)                           | `enabled` (`false`), `maxSize` (`50`), `ttl`, `flushInterval` (`0`)  |
| [`keepalive()`](/client/primitives/keepalive)            | `socket.quality` and `socket.latency` stores                | `interval` (`30_000`), `maxMissedPongs` (`2`)                        |
| [`quality()`](/client/primitives/quality)                | — (sets the quality limits)                                 | `thresholds`                                                         |
| [`query()`](/client/primitives/query)                    | — (adds URL query parameters)                               | a function that returns the parameters                               |
| [`intercept()`](/client/primitives/intercept)            | — (filters or changes incoming messages)                    | an interceptor function                                              |
| [`debug()`](/client/primitives/debug)                    | — (console logging)                                         | a boolean                                                            |
| [`platform()`](/client/platform/overview)                | `socket.online` store                                       | `environment`, `backgroundDisconnectMs`                              |

Times are in milliseconds. A "store" is a [reactive store](/client/overview#reactive-stores): a value you can read now or watch for changes.

A dash (—) in the "Adds to the socket" column means the primitive adds no method or store. It changes how the socket behaves instead. It works on the messages that go in and out, or on the connection's open and close events.

::note
**Plugins** are features you (or a package) write with `plugin()`. They work on the same messages as primitives. But a plugin does not add methods to the socket. You get its API with `Plugin.use(socket)`. See [Plugins](/client/plugins/overview).
::
