`intercept()` looks at every incoming message before your `on()` handlers do. The function you pass to it is called an **interceptor**. Use interceptors to filter, change, or add data to messages in one place. `intercept()` adds no methods to the socket.

```typescript [client/socket.ts]
import { client, connect, intercept } from '@livething/client'
import { Block } from '@livething/client/errors'
import type { HuddleSocket } from '@monorepo/server/huddle-definition'

export const socket = client<HuddleSocket>()(
  connect('wss://example.com/huddle'),

  // Observe: return nothing to leave the message as it is
  intercept((message) => {
    console.log(message.event, message.payload)
  }),

  // Drop: while "do not disturb" is on, notifications never reach the UI
  intercept((message) => {
    if (message.event === 'notification' && doNotDisturbIsOn())
      throw Block
  }),

  // Change: return a new message to replace it
  intercept((message) => ({
    ...message,
    payload: {
      ...(message.payload as object),
      receivedAt: Date.now(),
    },
  })),
)
```

## How an interceptor behaves

Each interceptor receives the parsed message: an object with the `event` name, the `payload`, and the `metadata` (extra details such as the channel name) when the server sent any. The interceptor then does one of three things:

- **Return nothing** (or return the same message). The message goes on to the next interceptor, and then to your handlers.
- **Return a new message.** The new message replaces the old one and goes on to the next interceptor.
- **Throw `Block`.** The message is dropped. No more interceptors run, and no `on()` handlers run. `Block` comes from `@livething/client/errors`.

Interceptors are synchronous. Return a message or throw. Do not return a promise.

::warning
**Only `Block` drops a message.** If an interceptor throws any other value, LiveThing does not drop the message. It sends the thrown value to `socket.onError`, skips that one interceptor, and runs the remaining interceptors and your handlers as usual. If you have no `onError` listener, the client throws the error again on a microtask, so it reaches the global error handler of the page or app. This way a bug in an interceptor cannot hide your messages. To drop a message on purpose, throw `Block`.
::

Interceptors run **before** the message is delivered anywhere: before your `socket.on()` handlers, your channel listeners (`room.on(...)`), and your stream loops and `onStream` handlers. So throwing `Block` drops a channel message or a stream chunk too, and a message you return is what those handlers receive.

Only [`dedup()`](/client/primitives/dedup) runs earlier: a duplicate is dropped before your interceptors see it. These messages never reach interceptors:

- LiveThing's own protocol messages, whose event names start with `__` (for example `__subscribeOk__` or `__error__`)
- a reply to your own `request()`, and a request that the server sends to the client (each belongs to one pending call)
- a message that `dedup()` dropped as a duplicate
- a message sent to a [plugin](/client/plugins/overview), which the plugin handles itself

Unlike [server-side intercepts](/server/lifecycle-and-intercept/intercept), a client interceptor gets **no context object**. If you need state, read it from the socket's [reactive stores](/client/overview#reactive-stores), such as `socket.state.get()`.

## Multiple interceptors

`intercept()` is the only primitive you can add more than once. The interceptors run in the order you list them. When one interceptor throws `Block`, the interceptors after it do not run.

```typescript [client/socket.ts]
import { client, connect, intercept } from '@livething/client'
import { Block } from '@livething/client/errors'
import type { InterceptFn } from '@livething/client'
import type { HuddleSocket } from '@monorepo/server/huddle-definition'

const dropDoNotDisturb: InterceptFn = (message) => {
  if (message.event === 'notification' && doNotDisturbIsOn())
    throw Block
}

const stampTime: InterceptFn = (message) => ({
  ...message,
  payload: { ...(message.payload as object), receivedAt: Date.now() },
})

export const socket = client<HuddleSocket>()(
  connect('wss://example.com/huddle'),
  intercept(dropDoNotDisturb), // runs first
  intercept(stampTime), // runs second, on the messages dropDoNotDisturb lets through
)
```
